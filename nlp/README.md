# nlp

`crusade -m nlp` is the neuro-linguistic programming trainer, a crusade mode. It opens a flat list of practice sessions, and each session is one page of touch typing. `n` opens vim for a new session's text, and `e` edits the selected session in vim. Sessions stay in the sql database `nlp`. Tab leaves the mode when a session is not being named or typed. In touch typing, ctrl+n marks the current line done and moves to the next line. ctrl+p clears the current line and the previous line and puts the cursor at the start of the previous line.
